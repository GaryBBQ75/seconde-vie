# Seconde Vie · Démo en ligne

Version de démonstration de Seconde Vie. Les écrans reprennent l’application Node.js. Les données initiales proviennent de son jeu de démonstration et restent fictives. Le site sauvegarde les modifications dans le navigateur. Le profil de test permet de découvrir les fonctions et le planning.

L’application de production utilise une base PostgreSQL et un déploiement Docker séparé. Le catalogue BnF et les accès individuels appartiennent à cette version.

Les sources de la démo se trouvent dans `dist/`. Aucun service de données n’est requis pour héberger ce site. Les bibliothèques de scan, d’étiquetage et la police sont livrées localement avec leurs licences.
